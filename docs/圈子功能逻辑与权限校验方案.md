# 「圈子」功能逻辑与权限校验方案（v=135 落地）

> 目标：发布与管理动态的操作体验对齐微信朋友圈 —— 浏览无门槛、发言有身份、删除限本人、过期即失效。本文档为完整功能逻辑与权限校验方案，v=135 已按此实现并上线。

## 1. 角色与权限总表

| 角色 | 浏览动态 | 查看详情 | 发帖 | 删本人帖 | 删他人帖 | 平台管理 |
|---|---|---|---|---|---|---|
| 未登录游客 | ✅ | ✅ | ❌ → 引导「登录 ›」 | ❌ | ❌ | — |
| 登录非会员 | ✅ | ✅ | ❌ → 引导「去开通 ›」 | ❌ | ❌ | — |
| 年费会员（有效） | ✅ | ✅ | ✅ | ✅ | ❌ | — |
| 年费会员（已过期） | ✅ | ✅ | ❌ → 引导「去续费 ›」 | ❌ → 引导续费 | ❌ | — |
| 平台后台 | — | — | — | — | ✅（审核/下架/删除/置顶） | ✅ |

**会员有效性定义**：`user.member === true 且 (memberExpire 为空 或 memberExpire ≥ 今天)`。两者任一不满足即为「非有效会员」，进入/发帖/删帖全部按非会员处理。

## 2. 发帖（对齐朋友圈：文字 + 配图 + 视频链接）

**入口**：圈子页右上「发动态」。

**内容形态**：文字（≤2000 字，自动打码手机号/微信/QQ/邮箱）+ 图片（最多 9 张，统一压缩管线）+ 视频号/视频链接（选填，1 条，须 `http(s)://` 开头，展示为「🎬 探访视频 · 播放」卡片）。

**发布前校验（3 道闸，顺序执行）**：

| # | 时机 | 校验 | 不通过 |
|---|---|---|---|
| 1 | 发布页打开 | 会员有效？（再查顾问已添加） | 过期/非会员 → 拦截页 + 开通/续费按钮；未加顾问 → 引导去添加 |
| 2 | 点击「发布动态」瞬间 | 二次校验会员有效（防页面停留期间过期）+ 视频链接格式 + 内容非空 + 已勾选规范 | toast 明确原因；会员问题直接跳转 #/vip |
| 3 | 服务端 `POST /api/post/check` | 会员 + 顾问 + 分类合法 + 长度 + 敏感信息打码 | 返回 `ok:false` + msg，前端 toast |

**发布后**：状态 `pending`（先发后审）→ 后台「圈子动态管理」审核通过后全圈可见；落库字段含 `ownerId`（发帖人登录手机号）——**归属的唯一判据**。

## 3. 删帖（仅本人）

**入口**：「我的动态」每条帖子下「🗑 删除」+ 详情页本人帖「🗑 删除这条动态」。他人帖子**不渲染**任何删除入口，直调接口也会被拦截。

**删除前校验（3 项，任一不满足即拦截）**：

| 校验 | 不通过提示 |
|---|---|
| ① 会员有效性（删帖瞬间） | 「会员已过期，续费后才能管理动态」/「仅会员可管理自己的动态」→ 跳 #/vip |
| ② 帖子存在性 | 「该动态不存在或已被删除」→ 刷新列表 |
| ③ 归属：`post.ownerId === 当前登录手机号` | 「只能删除自己发布的动态」 |

**交互**：朋友圈式二次确认（「删除这条动态？删除后不可恢复。」）→ 物理删除 → 云端同步 → toast「已删除」。

## 4. 边界处理

| 场景 | 处理 |
|---|---|
| 进入圈子（会员过期） | 顶部引导条变「会员已过期，续费后才能发动态 · 去续费 ›」 |
| 进入圈子（非会员/游客） | 引导条「开通年度会员…去开通 › / 登录 ›」；浏览不受限 |
| 帖子不存在 / 已被删除 | 详情页显示「动态不存在或已被删除」+ 返回圈子按钮 |
| 帖子被后台驳回 | 「我的动态」展示「已驳回 · 驳回原因：xxx」 |
| 帖子被后台下架 | 圈子列表/详情不再展示（status=off 过滤） |
| 多设备/多用户归属串号 | 归属用 `ownerId` 运行时比对，**不落 `mine` 字段**（历史遗留 mine 字段已不再参与判断，避免云同步后人人可见「我发的」） |
| 非法视频链接 | 前端拦截「视频链接需以 http(s):// 开头」；服务端同样校验 |
| 发布中会员恰好过期 | 点击发布瞬间二次校验拦截，跳转续费 |

## 5. 校验时机汇总（双端一致）

```
进入圈子 ──┬─ 渲染引导条（会员/过期/游客 三态）
           └─ 列表仅展示 status=on 的帖子
打开发布页 ──┬─ ①会员有效 → ②顾问已添加，否则拦截页
点击发布   ──┬─ ①会员有效(再查) → ②链接/内容/规范 → ③服务端 post/check
点击删帖   ──┬─ ①会员有效 → ②帖子存在 → ③ownerId 归属 → 确认弹窗 → 删除
服务端     ─── /api/post/check 会员+顾问+内容强校验（与前端同规则）
```
