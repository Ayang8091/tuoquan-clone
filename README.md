# 乐道AI · 复刻系统（用户端 + 后台管理端）

依据 13 张参考截图 + 321 秒操作录屏 + 线上站点（ledaoykj.com）真实文案，一比一复刻的完整可运行 SaaS 系统。纯前端实现（HTML/CSS/JS），以 `localStorage` 为数据库，**用户端与后台实时互通**：后台改配置/上沙龙/发公告，用户端刷新即见。

## 运行方式

```bash
cd tuoquan-clone
python3 -m http.server 8080          # 纯静态（登录走前端演示模式）
# 或带后端（推荐，登录/短信走真实 API 链路）：
node server.js                       # http://localhost:8080
# 后台    http://localhost:8080/admin.html   账号 admin / 123456
```

> 线上地址：https://tuoquan-ai.app.workbuddy.host/ （已部署，微信内置浏览器/手机浏览器均可打开）
> 重置演示数据：控制台执行 `Store.reset()` 后刷新。

## 登录 / 注册（微信授权 + 手机号绑定）

流程：**微信授权登录（或手机号登录）→ 未绑定手机号则强制进入绑定页 → 绑定完成即注册**。

- 微信内浏览器：公众号网页授权（snsapi_userinfo），在 `js/config.js` 配置 `mpAppId` 即启用真实授权
- 微信外浏览器：开放平台网站应用扫码登录，配置 `openAppId` 启用
- 手机号绑定：短信验证码（演示模式固定 `123456`；真实接入在 server.js 侧配置短信服务商 + `SMS_PROVIDER_KEY`）
- 登录态存 `localStorage.TQ_SESSION`，全部业务页有路由守卫
- **AppSecret 绝不能放前端**：真实换票据由 `server.js` 的 `/api/wx/exchange` 完成，环境变量 `WX_APPID/WX_SECRET`
- 未配置任何资质时自动走「演示模式」，全流程仍可体验

## 后台管理端（与用户端数据互通）

- **登录**：admin / 123456（sessionStorage 记忆登录态）
- **数据看板**：6 项核心指标、近 7 日成交趋势图（Canvas 手绘：金额面积线 + 引荐/锁粉柱）、最新订单表
- **老板资源管理**：增删改查、上下架（下架后用户端立即消失）、亮点徽章逐行编辑
- **沙龙活动管理**：增删改查、筹备中→报名中→已结束状态流转（报名中即在用户端沙龙 Tab 出现并可报名）
- **订单管理**：按类型/状态筛选；待对接→已对接→已完成流转；退款同步作废佣金
- **用户管理**：角色查看、一键开通分销员
- **分销与佣金**：三态佣金汇总、逐笔结算、锁粉客户归属表
- **合作线索**：完整申请内容（含预算档）、标记已合作
- **公告管理**：发布/编辑/删除，用户端「公告与规则」实时同步
- **系统配置**：会员价格、引荐价格、会员佣金 30%、沙龙佣金 50%、锁粉 60 天、引荐 24h 退款、主办方/站点/客服微信/企业微信码——保存后用户端所有对应文案与计算实时生效

## 技术说明

- 零依赖、零构建：`index.html`（用户端 SPA，hash 路由 20+ 页面）、`admin.html`（后台 SPA）
- `js/data.js`：数据层 + 种子数据（localStorage key `TQ_DB_V1`）
- 图片素材以渐变占位 + 文字还原视觉（封面/反馈截图/沙龙现场），替换 `coverStyle()` 与占位块即可接入真实图片
- 二维码为确定性仿真图案，替换 `qrSVG()` 为真实二维码库即可
